How it works

WASM Entropy Probe

Branch-heavy matrix multiply. Measures wall-clock timing noise from thermal throttle, DRAM refresh, and OS interrupts.

📈

Adaptive Early Exit

Checks signal confidence every 25 iterations. Obvious VMs stop at 50 iters (~0.9s). Real hardware runs longer for certainty.

🔬

Cross-Metric Heuristics

6 physically-linked relationships verified simultaneously. Spoofing one metric causes contradictions in the others.

🔒
